# T12 冻结真值 CER 与历史诊断评测

2026-10-30；用户选择方案 A：主评测之外，附录计算 DeepSeek D0/D1/D2 同一真实首行的探索性 CER。

## 变更点

- 主评测固定 `ground-truth-v1` 的十行、归档原始 OpenAI 预测和人工真值；line18/v2 不进入主指标。
- 双方 NFC 后按 Unicode 码点计算 Levenshtein；不 trim、折叠空格或删除标点，U+1123A、U+0020、Gujarati 数字全部计入。
- 以真值为 reference、模型为 hypothesis：模型多出字符记 insertion，模型漏真值字符记 deletion；固定等距回溯优先级保证可重算。
- 输出逐行 CER、微/宏平均、完全正确率、S/D/I、逐码点对齐、替换混淆及插入/删除频次。CER 不截断；空 hypothesis 计完整删除，空 reference 拒绝。
- 只读取版本归档中的原始预测，验证 provider/model/line/image/prediction/source 哈希，不用人工修订输出替代预测。
- DeepSeek D0/D1/D2 仅作为同一首行不同诊断设置的探索性附录；D1b 保留已有合成控制 CER，D3 标记取消。均不进入 OpenAI 主汇总。
- 无独立人工行框，因此不计算检测 recall/precision/IoU 或人工框 CER；明确主指标为用户确认裁剪上的转录 CER，阶段归因留 T13。
- 全过程离线，前后核验真值、源预测、缓存、selection 和预算账本哈希；零 API 调用、零新增费用。

## 测试计划

- 精确一致、单替换/删除/插入、空 hypothesis、拒绝空 reference、CER 可大于 1。
- 补充平面 Khojki 按一码点；NFC 等价；空格、word separator、Gujarati 数字计入。
- 重复字符/多条最短路径使用固定回溯；人工可算矩阵验证 S/D/I 与索引。
- 汇总微平均、宏平均、完全正确率、混淆/插入/删除频次和零失败计数。
- 真实 line15 必须是 hypothesis 额外 U+11235 的 insertion；九行 exact；若出现其他差异则集成测试失败。
- 真值、归档预测、provider/model、hash、缺失/重复行篡改拒绝；测试禁止网络和 API 客户端。
- DeepSeek 输入必须绑定同一首行图像；D1 空输出不能静默排除；D1b/D3 不混入真实扫描汇总。
- 同一冻结输入重复执行核心指标字节一致；完整 pytest、pip check 和独立 verify-evaluation。

## 假设与风险

- 当前无 Git 仓库，不执行 Git/Gitee 操作。
- 真值为模型辅助用户视觉确认，九行接受模型候选，存在锚定偏差；报告不能把低 CER 泛化为独立专家评测或集合准确率。
- 主样本是人工选择的清晰印刷行，且经历 line18 中途换入/最终恢复 v1；完整历史必须披露。
- 当前冻结结构预期九行 exact、line15 一次 insertion。这是输入完整性验收条件，不预先替代正式可重算结果。
- 只有一个主错误事件时描述为“唯一观察到的错误”，不泛化为稳定的最常见模式。
- 编辑类型不是因果归因。T12 不自动把 U+11235 insertion 判为 detection、recognition 或 Unicode mapping；T13 结合图像证据归因。
- DeepSeek 诊断请求的图像包/提示词不同，探索性 CER 只能说明各个已保存 case，不能形成第二模型总体指标。
